Prótesis de Mano Mioeléctrica

Control biológico mediante señales EMG para la rehabilitación biomecánica

📌 Sobre el Proyecto

Diseño e implementación de una prótesis robótica funcional accionada por señales electromiográficas (EMG) capturadas de la musculatura del antebrazo.

⚡ Control Mioeléctrico

Captura y filtrado de señales musculares en tiempo real para interpretar la intención de movimiento del usuario.

🦾 Mecánica & Impresión 3D

Estructura ligera impresas en 3D optimizada para agarres precisos y resistencia mecánica.

🧠 Procesamiento

Microcontrolador encargado del procesamiento de señales, algoritmos de detección de umbral y control de servomotores.

🛠️ Componentes Principales

Hardware

  • Sensor EMG (MyoWare / EMG Muscle Sensor)
  • Microcontrolador (Arduino / ESP32)
  • Servomotores de alto torque (MG996R)
  • Batería LiPo / Fuente de alimentación

Software & Control

  • Filtrado pasabandas y rectificación
  • Mapeo PWM para servomotores
  • Lógica de agarres (Pinch, Power Grip)
